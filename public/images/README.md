# Image folders

Drop your real photographs here. Keep the file names if you can — then you only change the
extension in `data/products.js` and `data/categories.js` (for example `.svg` → `.jpg`).

```
public/images/
  brand/         logo
  hero/          home hero photo
  about/         making / packing photo
  categories/    one photo per category
  products/      one photo per product
  instagram/     six square photos
```

Do not paste photos into the code. Put files in these folders, then point `image:` at the path.

Suggested size: portrait photos around 1600×2000px, Instagram squares around 1200×1200px.
